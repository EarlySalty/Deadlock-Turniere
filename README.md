# Deadlock-Turniere

Turnier-Plattform der **Deutschen Deadlock Community** — organisiert und verwaltet Community-Turniere für deutschsprachige Deadlock-Spieler.

## Features

- Turnier-Erstellung und -Verwaltung
- Teilnehmer-Anmeldung und Bracket-Generierung
- Ergebnis-Tracking und Chroniken-Archiv
- Discord-Integration für Benachrichtigungen

## Tech-Stack

- Backend: Python (FastAPI)
- Frontend: React + TypeScript
- Deployment: Linux mit Caddy als Reverse-Proxy
